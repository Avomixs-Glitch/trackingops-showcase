# TrackingOps Support

## Get the product

Visit [trackingops.vercel.app](https://trackingops.vercel.app) for the official TrackingOps product and installation experience.

## Product questions and feedback

This repository is a public showcase for private-source software. Public issues may be used for:

- presentation or documentation corrections;
- broken public links;
- accessibility feedback about the public showcase;
- non-sensitive product feedback or feature ideas.

When reporting a product problem, include the TrackingOps version, Windows version, expected behavior, observed behavior, and minimal reproduction steps. Remove usernames, hostnames, IP addresses, tokens, logs containing private data, and customer information before posting.

## Security and private data

Do not publish vulnerabilities, credentials, private logs, customer data, or identifying screenshots in an issue. Follow the instructions in [SECURITY.md](./SECURITY.md) and request a private contact channel from the repository owner when necessary.

## Source-code requests

TrackingOps is proprietary software. This showcase repository does not provide access to the private application codebase or internal deployment configuration.
