## Design principles

- The operator remains the decision authority.
- Live local evidence and connected organizational context stay visually distinct.
- AI receives explicit context and tool output instead of implying omniscience.
- Sensitive actions remain visible, deliberate and reviewable.
- The diagrams explain product boundaries without publishing private implementation details.
